# Leaflet 1.9.4

JavaScript/CSS oficiales, incluidos localmente para que ruta, marcadores y popups no
dependan de un CDN al abrir el HTML. Se conserva LICENSE de la versión original.

- https://leafletjs.com/download.html
- https://unpkg.com/leaflet@1.9.4/dist/leaflet.js
- https://unpkg.com/leaflet@1.9.4/dist/leaflet.css
- https://raw.githubusercontent.com/Leaflet/Leaflet/v1.9.4/LICENSE

El fondo de calles usa OpenStreetMap online. No se incluyen ni se descargan tiles para uso offline.
